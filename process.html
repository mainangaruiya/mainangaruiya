How I add the next case study

  1. Draft in my Claude Project — it already holds my voice, stack, and identity kit (instrument-panel tone, three-beat shape, the one-line claim). Drafting is a short conversation, not a rebuild from scratch each time.
  2. Copy the <article class="case-study"> block from work.html and fill the three beats: Problem (what was broken or missing), What I did (approach, key decisions, the one call worth explaining), What came of it (what it unblocked, what works now, or what it proved).
  3. Drop in a screenshot — swap the case-study-image-placeholder div for an <img class="case-study-image"> tag pointing to a real asset in the repo.
  4. Add a project card to the homepage grid in index.html and wire up the anchor link (work.html#project-id).
  5. Commit and push. GitHub Pages auto-deploys — no build step, no pipeline to maintain.
